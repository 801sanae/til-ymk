# 데이터와 정보

### 1. 데이터의 정의

 #### 데이터의 정의
 - 라틴어의 dare(주다), datum(주어진 것)에서 옴.
 - 보통 연구나 조사 등의 바탕이 되는 재료 혹은 자료를 의미한다.
 
#### 데이터의 특성
 - 데이터 : 있는 그대로의 사실, 객관적인 사실 의미
 - 정보 : 데이터로 부터 얻은 가공된 자료

 | 구분 | 형태 | 예
 | ----| ----| ----|
 | 존재적 특성 | 데이터 있는 그대로의 사실 | 날짜, 시간, 위치, 온도 등, 80,90점 성적표 점수 |
 | 당위적 특성 | 데이터로 부터 추촌, 예측, 전망, 추정을 위한 근거 | 평균90점, 80점 이상이면 A등급 |

#### 데이터의 유형

### 정성적 데이터 (Qualitative Data)
 - 언어와 문자 등 , **기준이 명확하지 않은 데이터**를 의미
### 정량적 데이터 (Quantitative Data)
 - 수치, 도형, 기호 등 **기준이 명확한 데이터**를 의미

 |구분|특징|예|
 |----|----|----|
 |정성적 데이터|기준이 명확하지 않은 데이터|언어, 문자 등|
 |정량적 데이터|기준이 명확한 데이터|수치, 도형, 기호 등|

### 정형 데이터
 - 고정된 틀이 있음, 연산 가능한 데이터, 관계형 데이터에 저장, 수집, 관리가 용이
### 비정형 데이터
 - 고정된 틀이 없음, 연산 불가능, 텍스트, 이미지, 오디오, 비디오 등 NoSQL에 저장된다.(RDS가 아닌)
### 준정형 데이터
 - 고정된 형태는 있지만 연산 불가능, JSON, XML 등 파일형태로 저장하며, 가공을 거쳐 정형 데이터로 변환 가능

|구분|특징|예|
|----|----|----|
|정형 데이터|고정된 틀이 있음, 연산 가능한 데이터, 관계형 데이터에 저장, 수집, 관리가 용이|관계형 데이터베이스, CSV, 엑셀,|
|비정형 데이터|고정된 틀이 없음, 연산 불가능, 텍스트, 이미지, 오디오, 비디오 등 NoSQL에 저장된다.(RDS가 아닌)|소셜 데이터, 댓글, 영상, 음성|
|준정형 데이터|고정된 형태는 있지만 연산 불가능, JSON, XML 등 파일형태로 저장하며, 가공을 거쳐 정형 데이터로 변환 가능|JSON, XML, 센서데이터|

#### 3. 암묵지와 형식지

### 암묵지

- 실무에서 경험을 통해 얻은 지식, 직관, 기술 등, 시행착오와 같은 경험에 의해 체득되어 명시적으로 표현하기 어려운 지식

### 형식지

- 명확하게 기술된 지식, 문서화된 정보, 규칙 등

### 암묵지와 형식지의 상화작용

- 암묵지가 형식지로 표출되고 연결되면, 지식이 형성됨.
- 개인의 내면화된 암묵지가 조직의 지식으로 ***공통화***되기 위해서 ***표출화***하고, 이를 다시 개인의 지식으로 ***연결화***되는 과정을 거치게 된다. 그리고 다시 개인에게 ***내면화***되는 과정을 거치게 된다.

|구분|과정|내용|상호작용|
|----|----|----|----|
|표출화|암묵지 → 형식지|개인의 암묵지 → 문서화된 정보|개인의 보유한 경험, 지식 등을 책이나 문서 등 외부로 표출하는 과정|
|연결화|형식지 → 형식지|개인의 형식지 → 조직의 형식지|개인의 보유한 경험과 외부지식이 연결하는 과정|
|내면화|형식지 → 암묵지|개인의 형식지 → 개인의 암묵지|개인의 보유한 정보를 개인의 경험과 결합하여 새로운 지식을 창출하는 과정|
|공통화|암묵지 → 암묵지|개인의 암묵지 → 조직의 암묵지|개인의 보유한 경험, 지식 등을 조직 내 다른 개인과 공유하고 공통적 지식을 생성하는 과정|

### 표출화 / 연결화 / 내면화 / 공통화 (SECI)

#### **표출화 (암묵지 → 형식지)**
- **의미**: 개인의 경험/노하우(암묵지)를 **문서·규칙·모델** 등 형식지로 표현하는 과정
- **포인트**: 조직이 **공유/저장/교육** 가능한 형태로 바뀜
- **예시**: 선배 업무 요령을 **체크리스트/매뉴얼**로 정리

#### **연결화 (형식지 → 형식지)**
- **의미**: 문서화된 지식(형식지)들을 **수집·분류·통합**하여 더 큰 체계로 만드는 과정
- **포인트**: “문서+문서”를 엮어 **표준/가이드/지식베이스**로 강화
- **예시**: 여러 문서를 합쳐 **표준 업무 프로세스** 만들기

#### **내면화 (형식지 → 암묵지)**
- **의미**: 문서/교재/가이드(형식지)를 학습·실습하여 **개인의 암묵지(체화된 실력)**로 만드는 과정
- **포인트**: “읽고 아는 것”을 넘어 **실제로 수행 가능한 상태**가 됨
- **예시**: 기출 풀이 + 오답정리 반복 → 문제 풀이 감이 몸에 익음

#### **공통화 (암묵지 → 암묵지)**
- **의미**: 개인의 암묵지를 **관찰·모방·피드백·공동 작업**을 통해 다른 사람에게 전수하는 과정
- **포인트**: 문서화가 어려운 노하우는 **OJT/멘토링**으로 전달되는 경우가 많음
- **예시**: 멘토링, 도제식 학습, 페어 작업으로 “감”을 따라 배우기

**10초 암기 요약**
- 표출화: 머릿속 → 문서  
- 연결화: 문서 → 문서(통합/체계화)  
- 내면화: 문서 → 내 실력(체화)  
- 공통화: 사람(경험) → 사람(경험 전수)
