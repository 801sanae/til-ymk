# 빅데이터 출현 배경

## 빅데이터의 출현 배경

1. 데이터의 양적 증가
-> 기술의 패러다임 시프트 현상으로 봐야된다.
2. 산업계의 변화
-> 양질 전환의 법칙 : 헤겔의 변증법에 기초하여, 양적 변화가 축적되면 질적 변화도 이루어진다.
3. 학계의 변화
4. 관련 기술의 발전

## 빅데이터의 기능과 변화

1. 빅데이터의 기능
```
> 빅데이터는 산업혁명의 석탄과 철
> 빅데이터는 21세기 원유
> 빅데이터는 렌즈
> 빅데이터는 플랫폼
```
2. 빅데이터가 만들어내는 변화(중요)

|구분|>>|변화|
|----|----|----|
|사전처리|->|사후관리|
|표본조사|->|전수조사|
|질|->|양|
|인과관계|->|상관관계|

3. 빅데이터의 등장에 따른 변화
    * 다양한 영역에서 변화 특히(기술과 인재 & 조직)

- 데이터의 변화
    - Volumn  |데이터의 양
    - Variety |데이터의 종류
    - Velocity|데이터의 수집 및 처리 속도

- 기술변화
    - 데이터 처리, 저장, 분석 및 아키텍처
    - 클라우드 컴퓨팅 활용

- 인재조직변화
    - 데이터사이언티스트 수요증가
    - 데이터 중심 조직 등장
