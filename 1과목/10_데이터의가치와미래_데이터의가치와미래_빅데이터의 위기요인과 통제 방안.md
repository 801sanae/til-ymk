# 빅데이터의 위기 요인과 통제 방안

## 1) 위기요인

### 1 사생활 침해
- 개인의 사생활 침해 위협을 넘어 사회 경제적 위협으로 변형
- 익명화 기술이 발전되엇느나, 정보의 오용될 때 의협의 크기는 큼

### 2 책임 원칙 훼손
- 빅데이터 기반 분석과 예측 기술이 발전하면서 정확도 증가, 분석 대상이 되는 사람들이 예측 알고리즘의 희생량이 될 가능성 증가.
### 3 데이터 오용
- 잘못된 인사이트를 비지니스에 적용할 경우 직접 손실 발생
- 과거 데이터를 과신하거나 오용하면 창조적인 제품 개발이 어렵다.
## 2) 통제방안

### 1) 사생활 침해의 통제 방안 -> 동의에서 **책임**으로
- 개인정보 제공자의 동의를 통해 해결하기 보단, 개인정보 사용자의 **책임**으로 해결
### 2) 책임 원칙 훼손의 통제 방안 -> 결과 기반 책임 원칙 고수
- 행동 결과를 보고 처벌
- 범죄를 저지를 것이라 예상되더라도, 현시점 아무런 범죄가 일어나지 않으면, 어떠한 조치를 취할 수 없다
### 3) 알고리즘 접근 허용
- 데이터 활용 로직인 알고리즘을 살핌으로 피해자를 구제할 수 있다
- 전문일력인 알고리즈미스트가 부상.

## 빅데이터 위기 요인과 통제 방안
|요인|통제방안|
|---|---|
|사생활 침해|동의에서 책임으로|
|책임 원칙 훼손|결과 기반 책임 원칙 고수|
|데이터 오용|알고리즘 접근 허용|

## 개인정보 비식별 기술리스트

|항목|예시|
|--|--|
|데이터 마스킹|기존 데이터 형식 유지한 채 임의의 값으로 대체|
|데이터 가명화|데이터를 다른 값으로 변경|
|총계 처리|총합 또는 평균으로 데이터를 보여줌|
|데이터 값 삭제|일부 데이터 삭제|
|데이터 범주화|데이터 값을 범주화하여, 범위로 제공|
