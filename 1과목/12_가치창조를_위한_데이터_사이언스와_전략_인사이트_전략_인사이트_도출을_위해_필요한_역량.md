# 가치창조를 위한 데이터 사이언스와 전략 인사이트

## 2. 전략 인사이트 도출을 위해 필요한 역량

### 1) 데이터 사이언스에 대한 이해와 역할

#### 1. 데이터 사이언스의 정의
- 데이터로부터 의미 있는 정보를 추출해내는 학문 : 데이터 사이언스
- 정형/비정형 막론하고 다양한 유형의 데이터를 대상한다.
- 데이터공학,수학,통계학,컴퓨터공학, 시각화, 해커의 사고방식, 해당 분야의 전문 지식을 종합한 학문으로 정의(위키피디아)

#### 2. 데이터 사이언스의 역할
- 데이터 마이닝을 넘어 전략적인 인사이트 도출을 위한 일련의 행위 모드 포괄하는 개념.
- 포괄적이고 충체적인 접근법 사용.
- 전략적 통찰 추구, 비즈니스 핵심 이슈에 답하며, 사업의 성과 견인한다.

### 2) 데이터 사이언스와 데이터 사이언티스트

#### 1. 데이터 사이언스 구성 요소
- **Analytics** : 수학, 확률모델, 머신러닝, 분석학, 패턴 인식과 학습, 불확실성 모델링 등
- **IT(Data management)** : 시그널 프로세싱, 프로그래밍, 데이터 엔지니어링, 데이터 웨어하우징, 고성능 컴퓨터
- **비즈니스 분석** : 커뮤니케이션, 프리젠테이션, 스토리텔링, 시각화 등
#### 2. 데이터 사이언티스트에게 요구되는 역량
- 하드스킬
1. 빅데이터에 대한 이론적 지식
2. 분석 기술에 대한 숙련

- 소프트스킬
1. 통찰력 있는 분석
2. 설득력 있는 전달
3. 다분야 간 협력<br>
eX) 비즈니스 분석은 소프트스킬
