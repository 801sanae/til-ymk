# 데이터베이스

### 데이터베이스 종류

1. 데이터베이스 종류

#### RDB
데이터가 행과 열로 이뤄진 테이블에 저장
데이터 저장방식은 구조적으로 엑셀과 유사<br>정형데이터 다루는데 특화

#### NoSql
Non-relational의 의미<br>비정형 데이터와 대용량의 데이터 분석 및 분산처리 용이


|RDB|NoSql|
|---|---|
|Oracle, MySQL(Oracle), MS-SQL(Microsoft),DB2, informix(IBM), MariaDB(Sun Microsystems), Derby(Apache), SQLite, HSQLDB, H2<br>Oracle, DB2, Informix는 객체 지향 개념을 도입한 것으로 오늘날 RDB는 객체지향 기능을 포함|Document-Oriented DataBase: CouchDB, MongoDB, Elasticsearch, Cloudant<br>Key-Value Store: Redis, DynamoDB(Amazon), Riak, Coherence, SimpleDB<br>Column-Oriented DataBase: HBase, Cassandra, Bigtable(Google), HyperTable

2. SQL

|종류|정의|문법|
|---|---|---|
|DDL|데이터 정의 언어|CREATE<br>ALTER<br>DROP<br>RENAME|
|DML|데이터 조작 언어|SELECT<br>INSERT<br>UPDATE<br>DELETE|
|DCL|데이터 제어 언어|GRANT<br>REVOKE|
|TCL|트랜잭션 제어 언어|COMMIT<br>ROLLBACK<br>SAVEPOINT|

3. 데이터베이스 구성 요소

|구분|정의|
|---|---|
|인스턴스|데이터베이스의 실행 상태|
|속성|데이터베이스의 특성|
|엔티티|데이터베이스의 구성 요소|
|메타데이터|데이터베이스의 메타데이터|
|인덱스|데이터베이스의 인덱스|
|데이터 마트(Data Mart)|개인이나 조직이 총체적인 관점에서 의사결정을 위해 공통의 형식으로 변환해 관리하는 역할|
|데이터 웨어하우스(Data Warehouse)|데이터 웨어하우스로부터 추출된 작은 데이터베이스로서 특정 목표를 달성하는 데 필요한 데이터를 제공하는 역할|
