# 데이터와 정보

### 1. DIKW 피라미드

#### 1-1. 데이터에서 지혜를 얻는 과정

- 데이터 : 객관적인 사실
- 정보 : 데이터를 가공, 처리와 데이터간의 연관 관계에서 의미도출된것. 내포하는 의미가 유용하지 않을수 있음
- 지식 : 데이터를 통해 도출된 정보를 구조화하고, 유의미있게 분류하고 개인 경험을 결합하여 교유 지식으로 내재화된 것
- 지혜 : 지식의 축척과 아이디어 결합된 산물

#### 1-2. DIKW 피라미드

            지혜 : A의 다른 물건도 저렴할 것이다.
           /---\
          | 지식 | : 더 저렴한 A로부터 연필을 사야겠다.
         /-------\
        |   정보   | : A연필이 더 저렴하다.
       /-----------\
      |    데이터    | : A는 100원 B는 200원에 연필을 판매한다.

### 2. 데이터 상식

#### 2.1 비트와 바이트

- 비트 : 0과 1로 구성된 데이터의 기본 단위
- 바이트 : 8비트로 구성된 데이터의 기본 단위

#### 2.2 데이터 단위

1 byte = 8 bit
1 KB = 1024 byte
1 MB = 1024 KB
1 GB = 1024 MB
1 TB = 1024 GB
1 PB = 1024 TB
1 EB = 1024 PB
1 ZB = 1024 EB
1 YB = 1024 ZB
